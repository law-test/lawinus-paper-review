# 김민규의 논문 심사실

인간80 원본과 최신 v129(213쪽·442각주), 이전 공개판을 기존 보기 메뉴에서 선택한다. 최신 수정지시서는 인간80 기준 1,133항목이다.

v128의 7개 보완을 승계하고 본문262·기존각주9·분할5를 반영했다. 최신 10% 분량 증가 허용에 따라 전체218쪽·152,676자 상한을 적용했다. 실제 213쪽·147,301자다. 구판200쪽 조건은 이력이다.

사용자 제공 v126 AI생성검사는 HWPX30%·PDF10%이며 v129는 미검사·5% 이하 여부 미확인이다. 이전 v126 검토자90점은 구판 평가다.

기존 원전·구판·개인메모와 AI민규 중지 상태를 보존했다. 새 기관 원문 PDF는 공개하지 않는다. GitHub Pages와 기존 Supabase를 사용하며 메뉴·화면배치를 유지한다.
