# 김민규의 논문 심사실

주택임차보증금반환채권의 행사 및 반환보장상의 법적 쟁점에 관한 연구

고려대학교 일반대학원 법학과 · 민법 · 지도교수 김제완

## 원고 · 2026-10-30

- 기본 화면은 인간80 심사본으로, PDF 266쪽·각주 444개다.
- 기존 보기 메뉴에서 최신 v121 수정본과 이전 v120 수정본을 선택한다.
- 최신 지시서는 인간80을 기준으로 한 v121 468항목이다. v120 판본에는 당시 452항목 지시서를 보존한다.
- 본문·목차·각주 위치와 공동 수정·개인 메모는 판본별로 관리한다. 기존 기록은 보존한다.
- 김규완 교수의 공개 연구자료와 예상 문답 20개를 제공한다. 예상 질문은 공개 업적을 토대로 한 준비자료다.
- 사용자 제공 v120 AI생성검사 결과는 PDF 12%·HWPX 28%로 구별한다. v121은 미검사이며 5% 이하를 확인하지 않았다.
- AI민규 답변 서버의 중지 상태를 유지한다.

PDF·HWPX·보조 MD와 원본 HWP는 `public/editions/`에서 배포한다.
실행 환경은 GitHub Pages와 기존 Supabase이며 비밀키를 프런트엔드에 넣지 않는다.

기존 메뉴와 화면 배치를 유지한다. 원고 갱신 요청을 메뉴 개편으로 확대하지 않는다.
