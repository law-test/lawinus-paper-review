# 김민규의 논문 심사실

주택임차보증금반환채권의 행사 및 반환보장상의 법적 쟁점에 관한 연구

고려대학교 일반대학원 법학과 · 민법 · 지도교수 김제완

- 기본 화면은 인간80 심사본(PDF 266쪽·각주 444개)이다.
- 기존 보기 메뉴에서 최신 v123과 이전 v122·v121·v120 수정본을 선택한다.
- 최신 지시서는 인간80 기준 v123 566항목이다. 이전 지시서는 해당 판본에 보존한다.
- 임대인 사망에 따른 소송·집행의 처리, 상속포기·한정승인과 상속재산파산을 새 항목의 다섯 문단으로 보완했다.
- 클로드 검토의견을 실제 v122와 대조해 반영하고, 각주 32개 정리·5개 신설에 따른 최종 417개 각주의 번호와 내부 재인용을 맞췄다.
- 관련 원전의 선별 부분을 검토했으며 교과서 전권 정독으로 표시하지 않는다.
- 김규완 교수 공개 연구자료와 예상 문답 20개를 제공한다. 실제 심사 질문이나 평가기준은 아니다.
- 사용자 제공 v120 AI생성검사는 PDF 12%·HWPX 28%로 구별한다. v121·v122·v123은 미검사이며 5% 이하 여부를 확인하지 않았다.
- 기존 개인 메모·공동 수정 기록과 AI민규 중지 상태를 보존한다.

PDF·HWPX·보조MD와 원본HWP는 public/editions/에서 배포한다. 실행 환경은 GitHub Pages와 기존 Supabase다. 기존 메뉴·화면배치를 유지한다.
