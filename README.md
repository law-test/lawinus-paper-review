# 김민규의 논문 심사실

주택임차보증금반환채권의 행사 및 반환보장상의 법적 쟁점에 관한 연구

고려대학교 일반대학원 법학과 · 민법 · 지도교수 김제완

- 기본 화면은 인간80 심사본(PDF 266쪽·각주 444개)이다.
- 기존 보기 메뉴에서 최신 v126(199쪽·각주 442개)와 이전 v124·v123·v122·v121·v120 수정본을 선택한다.
- 최신 지시서는 인간80 기준 v126 894항목이다. 이전 판본과 지시서는 해당 판본에 보존한다.
- 요건·예외·인용 근거를 유지하면서 중복 설명을 압축하고 동일 논점의 문단을 통합했다.
- 검토자 평가는 90/100점이며 공식 심사점수나 AI검사 수치가 아니다. 상세 근거는 최신 판본의 평가문에 있다.
- 사용자 제공 v122 AI생성검사는 PDF 11%·HWPX 25%이다. 이전 v120 PDF 12%·HWPX 28%와 구별한다. v123·v124·v125·v126은 미검사이며 5% 이하 여부를 확인하지 않았다.
- 원전은 관련 부분을 선별 검토했다. 교과서 전권의 신규 정독으로 표시하지 않는다.
- 김규완 교수 공개 연구자료와 예상 문답 20개를 제공한다. 실제 심사 질문이나 평가기준은 아니다.
- 개인 메모·공동 수정 기록과 AI민규 중지 상태를 보존한다.

PDF·HWPX·보조MD와 원본HWP는 public/editions/에서 배포한다. GitHub Pages와 기존 Supabase를 사용하며 기존 메뉴·화면배치를 유지한다.
