# 김민규의 논문 심사실

주택임차보증금반환채권의 행사 및 반환보장상의 법적 쟁점에 관한 연구

고려대학교 일반대학원 법학과 · 민법 · 지도교수 김제완

- 기본 화면은 인간80 심사본(PDF 266쪽·각주 444개)이다.
- 기존 보기 메뉴에서 최신 v122와 이전 v121·v120 수정본을 선택한다.
- 최신 지시서는 인간80 기준 v122 475항목이다. v121 468항목·v120 452항목은 해당 판본에 보존한다.
- 온주 관련 해설과 지원림 제23판 116쪽, 이시윤·조관행 제9개정판 140쪽, 법원실무제요 2020 5권 중 관련 282쪽을 선별 검토했다. 전권 정독이 아니다.
- 임차권등기 말소 순서, 양도·전대, 압류·추심, 배당요건, 임차권등기 후 새 소액임차인의 최우선변제권 배제, 조정서 집행력을 보완했다. 본문 3곳·기존 각주 6곳·서지 2행이며 새 각주는 없다.
- 김규완 교수 공개 연구자료와 예상 문답 20개를 제공한다. 실제 심사 질문이나 평가기준은 아니다.
- 사용자 제공 v120 AI생성검사는 PDF 12%·HWPX 28%로 구별한다. v121·v122는 미검사이며 5% 이하 여부를 확인하지 않았다.
- 기존 개인 메모·공동 수정 기록과 AI민규 중지 상태를 보존한다.

PDF·HWPX·보조MD와 원본HWP는 public/editions/에서 배포한다. 실행 환경은 GitHub Pages와 기존 Supabase다. 기존 메뉴·화면배치를 유지한다.
